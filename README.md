Project Title

ATM Withdrawal Simulation

Aim

The aim of this project is to simulate an ATM withdrawal system that allows a user to withdraw money, checks for sufficient balance, and displays the updated account balance.

Topic Name

Simulate ATM Withdrawal

Technology Stack

Programming Language: C

Compiler: GCC / Turbo C / Any C Compiler

Project Description

This project is a basic console-based application written in C.
It demonstrates how an ATM withdrawal process works by:

Taking a withdrawal amount from the user

Checking whether the amount is valid

Verifying if the account has sufficient balance

Updating and displaying the remaining balance after withdrawal

The program uses conditional statements (if and else) to make decisions.

How the Program Works

An initial balance is assigned to the user.

The user is asked to enter the withdrawal amount.

The program checks whether the entered amount is greater than zero.

If the amount is valid, it checks whether the balance is sufficient.

If sufficient balance is available, the withdrawal is successful.

The balance is updated and displayed.

If the balance is insufficient or the amount is invalid, an error message is shown.

Expected Output

Updated balance after successful withdrawal

Insufficient balance message if amount exceeds balance

Invalid amount message if the entered value is zero or negative

Sample Input
Enter amount to withdraw: 1000

Sample Output
Withdrawal successful!
Updated Balance: 4000

Conclusion

This project helps beginners understand basic programming concepts such as:

Variables

Input and output

Conditional statements

Simple logic building
